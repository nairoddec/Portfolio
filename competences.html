Environnements de Développement & Outils

VS Code

Mon éditeur principal au quotidien. Je l'ai configuré sur mesure pour être le plus efficace possible, que ce soit pour mes développements web ou l'écriture de mes scripts PowerShell et Batch.

Cursor

J'utilise cet IDE assisté par l'IA pour coder plus intelligemment. Il m'aide énormément à accélérer mes phases de refactoring, générer des tests répétitifs ou cibler rapidement l'origine d'un bug.

Suite JetBrains (IntelliJ)

Mon environnement de prédilection pour le Java. Je l'utilise pour mes projets back-end nécessitant une analyse de code approfondie et une gestion d'architecture robuste (Java EE, Spring).

Eclipse

J'ai consolidé le Java sur cet outil durant mon stage, et je continue de l'utiliser régulièrement pour les projets universitaires ou pour intervenir sur du code existant qui nécessite cet environnement spécifique.

Git & GitHub

Je versionne systématiquement mes projets avec Git. GitHub me sert à la fois de sauvegarde de mon travail, mais aussi d'outil pour collaborer et suivre proprement l'avancée de mes développements.

VMware / VirtualBox

Des outils centraux dans mon cursus RACA. Je les utilise constamment pour monter des architectures réseaux de test, simuler des serveurs et m'entraîner à l'administration système locale.

Postman

Mon outil de référence dès que je développe une API. Il me fait gagner un temps précieux pour créer, valider mes requêtes HTTP et déboguer les échanges client-serveur avant même d'écrire le Front-End.

Figma

Je préfère ne jamais coder une interface à l'aveugle. J'utilise Figma pour prototyper mes idées en amont, comme je l'ai fait pour concevoir mes maquettes lors de ma mission de refonte UI/UX en stage.
